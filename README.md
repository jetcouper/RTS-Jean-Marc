# Pour l'utilisateur

## - Générale
### &nbsp;     - La commande F11 permet de quitter le Fullscreen.
### &nbsp;    - Peut quitter le programme en appuyant sur "q".

## - Le Login
### &nbsp;    - Vous pouvez vous connecter en tant qu'invité en appuyant sur la ligne "Connectez-vous en tant qu'invité".
### &nbsp;    - Vous pouvez enregistrer un nouvel utilisateur.
### &nbsp;    - Vous pouvez vous "Login" pour entrer dans le menu (Si l'utilisateur est existant).

## - Le menu
### &nbsp;    - Vous pouvez utiliser le bouton Quitter et Jouer uniquement, le reste sera implémenté plus tard.

## - Le menu de la partie.
### &nbsp;    - Vous pouvez commencer une partie avec le bouton "Commencer"
### &nbsp;    - Vous pouvez charger une partie sauvegarder (S'il y en a.), faite d'abord le bouton "Actualiser" pour afficher la sauvegarde appartenant au joueur.
### &nbsp;    - Vous pouvez supprimer la sauvegarde du joueur
### &nbsp;    - Vous pouvez ajouter des IA au niveau de la vue.

## - La partie
### &nbsp;    - Vous pouvez vous déplacer dans la carte en retenant votre clique gauche sur carte et vous déplacer dans la direction que vous voulez. 
### &nbsp;    - Vous pouvez voir un carré sur la mini-carte pour savoir où vous êtes. Vous pouvez aussi vous déplacer sur la carte en cliquant dans la mini-carte.
### &nbsp;    - Vous pouvez accéder au menu de la partie en appuyant sur <escape>.
### &nbsp;    - Vous pouvez sauvegarder une partie depuis le menu de la partie.
### &nbsp;    - Vous pouvez quitter une partie depuis le menu de la partie.
### &nbsp;    - (Pour l'instant) Vous ne pouvez pas attaquer les IA (Fonction attaquer non-terminé).

## - Victoire
### &nbsp;    - Le choix de type de partie se trouve sous le bouton "Ajouter AI" une fois qu'on est dans le lobby dans la section "Mode de jeu".
### &nbsp;    - Conquête : Pour gagner il faut détruire toutes les unités de chaque équipe.
### &nbsp;    - Commerce : Pour gagner il faut arriver à ramasser un certain nombre de ressources.

## - Nouveaux bâtiments
### &nbsp;    - Le moulin : Génère de la nourriture chaque intervalle de temps (environ 3 secondes)

## - Le AI
### &nbsp;    - Nous n'avons pas eu le temps de le terminer.
### &nbsp;    - Si vous voulez voir le AI jouer, il se pourrait qu'un joueur AI paraîsse immobile, il faut aller en voir un autre. Il y a un problème avec les joueurs AI. Il vont faire toutes leurs actions un après l'autre, c'est-à-dire que ce n'est qu'une fois qu'un joueur AI termine tout son processus de décision que le prochain commencera le sien. Ils le font en ordre (AI 1, AI 2, etc.). Ainsi, si un AI parait immobile, c'est parce que ce n'est pas encore son "tour". *Le premier aparait en haut de la map*
### &nbsp;    - Le AI a un processus de décision court, il va construire quelques bâtiments et unités, puis lorsque c'est terminé il laisse les ouvriers ramasser les ressources automatiquement. C'est à ce moment que le prochain AI commence ses actions.
