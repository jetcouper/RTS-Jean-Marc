# Pour l'utilisateur

## - Générale
### &nbsp;     - La commande F11 permet de quitter le Fullscreen.
### &nbsp;    - Peut quitter le programme en appuyant sur "q".

## - Le Login
### &nbsp;    - Vous pouvez vous connecter en tant qu'invité en appuyant sur la ligne "Connectez-vous en tant qu'invité".
### &nbsp;    - Vous pouvez enregistrer un nouvelle utilisateur.
### &nbsp;    - Vous pouvez vous "Login" pour entrez dans le menu (Si l'utilisateur est existant).

## - Le menu
### &nbsp;    - Vous pouvez utiliser le bouton Quitter et Jouer uniquement, le reste sera implémenté plus tard.

## - Le menu de la partie.
### &nbsp;    - Vous pouvez commencer une partie avec le bouton "Commencer"
### &nbsp;    - Vous pouvez charger une partie sauvegardé (S'il y en a.), faite d'abord le bouton "Actualiser" pour afficher la sauvegarde appartenant au joueur.
### &nbsp;    - Vous pouvez supprimer la sauvegarde du joueur
### &nbsp;    - Vous pouvez ajouter des IA au niveau de la vue.(Pas implémenté dans la partie, donc juste une IA disponible)

## - La partie
### &nbsp;    - Vous pouvez vous déplacer dans la carte en cliquant sur carte et la mini-carte.
### &nbsp;    - Vous pouvez accéder au menu de la partie en appuyant sur <escape>.
### &nbsp;    - Vous pouvez sauvegarder une partie depuis le menu de la partie.
### &nbsp;    - Vous pouvez quitter une partie depuis le menu de la partie.
### &nbsp;    - (Pour l'instant) Vous ne pouvez pas attaquer les IA (Fonction attaqué non-terminé).
